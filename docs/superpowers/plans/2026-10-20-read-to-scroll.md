# Read-to-Scroll Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An iOS app that blocks Instagram until you earn time by reading in Apple Books (1 min reading = N min Instagram), with an adjustable ratio and daily cap.

**Architecture:** A SwiftUI app plus three Screen Time extensions (DeviceActivity monitor, shield configuration, shield action), sharing state through App Group UserDefaults. All business rules live in a pure Swift package `RewardCore` (no Apple Screen Time imports), which is unit-tested with `swift test`. A thin `Shared/` layer bridges RewardCore to FamilyControls / ManagedSettings / DeviceActivity.

**Tech Stack:** Swift 5 language mode, SwiftUI, iOS 17+, FamilyControls, DeviceActivity, ManagedSettings(UI), XcodeGen, Swift Package Manager, XCTest.

**Spec:** `/Users/joshhinder/.claude/plans/i-want-to-create-witty-riddle.md`

## Global Constraints

- Project root: `~/ReadToScroll`. The Xcode project is generated from `project.yml` by XcodeGen; `*.xcodeproj` is git-ignored.
- Team ID `M37XS4G2JJ`; bundle prefix `com.joshhinder.readtoscroll`; App Group `group.com.joshhinder.readtoscroll`.
- Deployment target iOS 17.0. `SWIFT_VERSION: 5.0` for app targets (avoids Swift 6 strict-concurrency errors on ManagedSettings statics).
- Defaults: ratio 3, daily cap 60 min. Allowed ranges: ratio 1–10, cap 10–120.
- Authorization: `.individual` (personal device, no parental flow).
- Balance resets at local midnight. Stricter settings apply immediately; looser settings (higher ratio, higher cap, turning enforcement off) are queued until the next day.
- The whole of Instagram is locked (the API is app-level).
- Screen Time APIs don't work in the Simulator: anything touching them is verified on a physical iPhone.
- Extensions have a ~6 MB memory limit: extensions import only RewardCore + `Shared/`, with no extra dependencies.

## Review Focus

1. **Threshold events arriving duplicated or out of order** → counters must never go down or double-count (ledger keeps the max). Tested in Task 3.
2. **App/extension not run for several days** (phone off, no events) → the next load resets to today and applies queued settings exactly once. Tested in Task 3.
3. **Tightening the cap below already-spent minutes** → remaining clamps to 0 (never negative) and Instagram is shielded immediately, with no wait for the next event. Tested in Task 3 (clamp); the app re-applies the shield after saving settings in Task 7.
4. **Mixed change (ratio looser, cap stricter in one save)** → the cap applies now and the ratio is queued. Tested in Task 2.
5. **Clock moving backwards (travel / time-zone change)** → must not wipe today's ledger. Tested in Task 3.

`RewardPolicy.swift`:
```swift
/// The rules for earning Instagram time. Values are clamped to the allowed ranges.
public struct RewardPolicy: Codable, Equatable, Sendable {
    public static let ratioRange = 1...10
    public static let capRange = 10...120
    public static let `default` = RewardPolicy(ratio: 3, dailyCap: 60, enforced: true)

    /// Instagram minutes earned per minute of reading.
    public let ratio: Int
    /// Most Instagram minutes that can be earned in one day.
    public let dailyCap: Int
    /// When false, Instagram is never shielded.
    public let enforced: Bool

    public init(ratio: Int, dailyCap: Int, enforced: Bool = true) {
        self.ratio = min(max(ratio, Self.ratioRange.lowerBound), Self.ratioRange.upperBound)
        self.dailyCap = min(max(dailyCap, Self.capRange.lowerBound), Self.capRange.upperBound)
        self.enforced = enforced
    }

    public func earned(readMinutes: Int) -> Int {
        min(max(readMinutes, 0) * ratio, dailyCap)
    }
}
```

```swift
/// The active policy plus any looser change waiting for the next day.
public struct SettingsState: Codable, Equatable, Sendable {
    public private(set) var active: RewardPolicy
    public private(set) var pending: RewardPolicy?

    public init(active: RewardPolicy = .default, pending: RewardPolicy? = nil) {
        self.active = active
        self.pending = pending
    }

    /// The latest values the user asked for (what the settings screen shows).
    public var requested: RewardPolicy { pending ?? active }

    /// Stricter parts of `desired` apply now; looser parts wait for `rollOver()`.
    public mutating func request(_ desired: RewardPolicy) {
        let now = RewardPolicy(
            ratio: min(active.ratio, desired.ratio),
            dailyCap: min(active.dailyCap, desired.dailyCap),
            enforced: active.enforced || desired.enforced
        )
        active = now
        pending = desired == now ? nil : desired
    }

    /// Called once when a new day starts.
    public mutating func rollOver() {
        guard let pending else { return }
        active = pending
        self.pending = nil
    }
}
```

```swift
/// Reading and Instagram minutes for one day.
public struct DayLedger: Codable, Equatable, Sendable {
    public let day: String
    public private(set) var readMinutes = 0
    public private(set) var spentMinutes = 0

    public init(day: String) { self.day = day }

    // Threshold events are cumulative, so keep the highest seen:
    // duplicates and out-of-order delivery are harmless.
    public mutating func recordRead(totalMinutes: Int) { readMinutes = max(readMinutes, totalMinutes) }
    public mutating func recordSpent(totalMinutes: Int) { spentMinutes = max(spentMinutes, totalMinutes) }
}
```

```swift
/// Name of a DeviceActivity threshold event, encoded as "read.5" or "spend.12".
public struct EventName: Hashable, Sendable {
    public enum Kind: String, Sendable { case read, spend }

    public let kind: Kind
    public let minutes: Int

    public init(kind: Kind, minutes: Int) {
        self.kind = kind
        self.minutes = minutes
    }

    public init?(rawValue: String) {
        let parts = rawValue.split(separator: ".")
        guard parts.count == 2,
              let kind = Kind(rawValue: String(parts[0])),
              let minutes = Int(parts[1]), minutes > 0 else { return nil }
        self.init(kind: kind, minutes: minutes)
    }

    public var rawValue: String { "\(kind.rawValue).\(minutes)" }
}

public enum Tuning {
    /// Minutes between threshold events. Set by the on-device spike (Task 6).
    public static let thresholdStep = 1
}

public enum EventPlan {
    /// Events are registered once for the widest allowed settings (cap 120, ratio 1),
    /// so changing ratio/cap never requires re-registering mid-day.
    public static func events(step: Int = Tuning.thresholdStep) -> [EventName] {
        let maxMinutes = RewardPolicy.capRange.upperBound
        let minutes = Array(stride(from: step, through: maxMinutes, by: step))
        return minutes.map { EventName(kind: .read, minutes: $0) }
            + minutes.map { EventName(kind: .spend, minutes: $0) }
    }
}
```

`AppState.swift`:
```swift
/// Everything persisted in the App Group: settings plus today's ledger.
public struct AppState: Codable, Equatable, Sendable {
    public var settings: SettingsState
    public private(set) var ledger: DayLedger

    public init(day: String, settings: SettingsState = SettingsState()) {
        self.settings = settings
        self.ledger = DayLedger(day: day)
    }

    /// Call before every read. A later day resets the ledger and applies queued settings once;
    /// an earlier day (clock moved back) is ignored.
    public mutating func advance(to day: String) {
        guard day > ledger.day else { return }
        ledger = DayLedger(day: day)
        settings.rollOver()
    }

    public mutating func record(_ event: EventName) {
        switch event.kind {
        case .read: ledger.recordRead(totalMinutes: event.minutes)
        case .spend: ledger.recordSpent(totalMinutes: event.minutes)
        }
    }

    public var earnedMinutes: Int { settings.active.earned(readMinutes: ledger.readMinutes) }
    public var remainingMinutes: Int { max(0, earnedMinutes - ledger.spentMinutes) }
    public var shouldShield: Bool { settings.active.enforced && remainingMinutes == 0 }
```

```swift
import Foundation
import FamilyControls
import RewardCore

enum AppGroup {
    static let id = "group.com.joshhinder.readtoscroll"
}

/// App Group persistence shared by the app and all extensions.
struct SharedStore {
    private let defaults = UserDefaults(suiteName: AppGroup.id)!

    private enum Key {
        static let state = "state.v1"
        static let earn = "earnSelection.v1"
        static let spend = "spendSelection.v1"
        static let log = "log.v1"
    }

    /// Loads state and rolls it forward to today (resetting the ledger / applying queued settings if needed).
    func loadState(now: Date = .now) -> AppState {
        let today = DayKey.string(for: now)
        var state = read(AppState.self, Key.state) ?? AppState(day: today)
        state.advance(to: today)
        return state
    }

    func save(_ state: AppState) { write(state, Key.state) }

    @discardableResult
    func update(now: Date = .now, _ body: (inout AppState) -> Void) -> AppState {
        var state = loadState(now: now)
        body(&state)
        save(state)
        return state
    }

    var earnSelection: FamilyActivitySelection {
        get { read(FamilyActivitySelection.self, Key.earn) ?? FamilyActivitySelection() }
        nonmutating set { write(newValue, Key.earn) }
    }

    var spendSelection: FamilyActivitySelection {
        get { read(FamilyActivitySelection.self, Key.spend) ?? FamilyActivitySelection() }
        nonmutating set { write(newValue, Key.spend) }
    }

    var eventLog: EventLog { read(EventLog.self, Key.log) ?? EventLog() }

    func log(_ line: String) {
        var log = eventLog
        log.append("\(Date.now.formatted(date: .omitted, time: .standard))  \(line)")
        write(log, Key.log)
    }

    private func read<T: Decodable>(_ type: T.Type, _ key: String) -> T? {
        defaults.data(forKey: key).flatMap { try? JSONDecoder().decode(T.self, from: $0) }
    }

    private func write<T: Encodable>(_ value: T, _ key: String) {
        defaults.set(try? JSONEncoder().encode(value), forKey: key)
    }
}
```

```swift
import FamilyControls
import SwiftUI
import RewardCore

@MainActor
final class AppModel: ObservableObject {
    private let store = SharedStore()

    @Published private(set) var state: AppState
    @Published var earnSelection: FamilyActivitySelection
    @Published var spendSelection: FamilyActivitySelection
    @Published private(set) var isAuthorized = AuthorizationCenter.shared.authorizationStatus == .approved
    @Published private(set) var monitoringError: String?

    init() {
        state = store.loadState()
        earnSelection = store.earnSelection
        spendSelection = store.spendSelection
    }

    var setupProblems: [String] {
        SetupCheck.problems(
            earnItemCount: earnSelection.applicationTokens.count + earnSelection.webDomainTokens.count,
            spendItemCount: spendSelection.applicationTokens.count + spendSelection.webDomainTokens.count
        )
    }

    var isMonitoringReady: Bool {
        isAuthorized && setupProblems.isEmpty
            && !store.earnSelection.applicationTokens.isEmpty
            && !store.spendSelection.applicationTokens.isEmpty
    }

    func requestAuthorization() async {
        do {
            try await AuthorizationCenter.shared.requestAuthorization(for: .individual)
        } catch {
            monitoringError = "Screen Time permission was not granted: \(error.localizedDescription)"
        }
        isAuthorized = AuthorizationCenter.shared.authorizationStatus == .approved
    }

    func saveSelectionsAndStart() {
        guard setupProblems.isEmpty else { return }
        store.earnSelection = earnSelection
        store.spendSelection = spendSelection
        do {
            try Monitoring.start(earn: earnSelection, spend: spendSelection)
            monitoringError = nil
            store.log("monitoring started (\(EventPlan.events().count) events)")
        } catch {
            monitoringError = "Couldn't start monitoring: \(error.localizedDescription)"
        }
        refresh()
    }

    /// Re-reads shared state (the extension may have changed it) and re-applies the shield.
    func refresh() {
        state = store.loadState()
        store.save(state)
        isAuthorized = AuthorizationCenter.shared.authorizationStatus == .approved
        if isAuthorized { Shielding.apply(state, spend: store.spendSelection) }
    }

    func requestPolicy(_ policy: RewardPolicy) {
        state = store.update { $0.settings.request(policy) }
        Shielding.apply(state, spend: store.spendSelection)
    }

    var eventLog: [String] { store.eventLog.entries.reversed() }
}
```
